# RDR2 Amber KDE — VS Code / VSCodium Theme

A warm, low-eye-strain dark theme inspired by the sepia mist and golden amber lighting of *Red Dead Redemption 2*, designed to blend seamlessly with warm KDE Plasma / Dolphin dark window themes.

## Features
- **KDE Surface Integration:** Sidebars (`#1e1a16`) and editor backgrounds (`#161310`) match warm KDE dark window surfaces.
- **Jupyter Notebook (`.ipynb`) Ready:** Distinct cell backgrounds, recessed output containers, and clear amber focus borders.
- **Tuned Syntax Highlighting:** High-legibility pastel earth tones for Python, JSON, Markdown, and terminal output.

## Installation from `.vsix`

### Command Line (VSCodium / VS Code)

codium --install-extension rdr2-amber-kde-1.0.0.vsix
